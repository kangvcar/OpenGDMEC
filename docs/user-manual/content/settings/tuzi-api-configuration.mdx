# 兔子 API 配置教程

OpenGDMEC 只暴露图片生成，接入方式收敛成一句话：**拿一把管理员发来的 Key，粘到弹窗里，就能生图。**
API 地址、供应商与默认模型都由应用内置，使用者不需要填写。

:::note
**API 地址：** `https://api.tu-zi.com/v1`（应用已内置）　　**API Key：** 由管理员发放的子密钥
:::

## 配置流程

管理员创建令牌 → 把 Key 发给使用者 → 在 OpenGDMEC 的引导弹窗里粘贴 → 选模型开始生成。

:::tip
API Key 等同于账户凭证。不要把它发到群聊、截图或公开仓库；如果怀疑泄露，请联系管理员禁用后重新发放。
:::

## 一、（管理员）在兔子 API 创建令牌

### 步骤 1：进入 API 控制台

打开 [兔子 API 控制台](https://api.tu-zi.com/)，登录后进入“控制台 → API 密钥”。如果已有可用令牌，可以直接跳到步骤 3。

<img src="assets/tuzi-api/step-1.png" alt="兔子 API 控制台的 API 密钥页面" class="step-screenshot" />
<p class="screenshot-caption">在控制台的 API 密钥页面创建或管理令牌</p>

### 步骤 2：创建令牌并选择分组

点击“新建”，填写令牌名称，在“令牌分组”中选择需要使用的分组，然后点击“提交”。模型分组可在兔子 API 的“模型广场”查看。

<img src="assets/tuzi-api/step-2.png" alt="创建令牌并选择令牌分组" class="step-screenshot" />
<p class="screenshot-caption">设置令牌名称、分组并提交</p>

:::note
**用量与可用模型由这把子密钥决定。** 需要限制某位使用者的模型范围或次数时，改的是后台的子密钥，前端不需要任何配合。
:::

### 步骤 3：复制令牌密钥

回到 API 密钥列表，复制刚创建的令牌密钥。密钥通常只在创建或首次查看时完整显示，请先保存到安全位置。

<img src="assets/tuzi-api/step-3.png" alt="从 API 密钥列表复制令牌密钥" class="step-screenshot" />
<p class="screenshot-caption">从 API 密钥列表复制令牌密钥</p>

### 步骤 4：把 Key 交给使用者

把密钥**单独发给本人**（微信私聊、企业微信等）。不要发到群聊、不要截图、不要生成带密钥的链接——链接一旦被转发，密钥就等于泄露。

## 二、（使用者）在 OpenGDMEC 填入 Key

### 步骤 5：打开「配置 API Key」弹窗

打开 OpenGDMEC，点击工具栏上的**企业微信图标**，弹出“配置 API Key”窗口。窗口左侧是管理员二维码，右侧是两步说明。

:::tip
还没配置 Key 就直接点了生成也不要紧：应用会拦下这次请求、自动弹出同一个窗口，并在上方给出一行提示。
:::

### 步骤 6：粘贴 Key 并保存

在第 2 步的输入框里粘贴管理员发来的密钥，点击**保存并开始**。保存成功后窗口关闭，配置立即生效。

:::note
**密钥只保存在你自己的浏览器里**，不会上传到服务器。换浏览器、换设备或清空浏览器数据后，需要重新粘贴一次。
:::

## 三、完成第一次生成

### 步骤 7：选择模型

回到画布，在模型选择器里选择一个图片模型。应用已预设默认模型，不改也能直接开始。

### 步骤 8：提交一次生成任务

输入一条简单的图片描述，点击发送。能够正常进入生成状态并返回图片，说明配置已经生效。

## 常见问题

### 提示「缺少 API Key」

还没有粘贴密钥。点工具栏的企业微信图标打开弹窗，把管理员发来的 Key 粘进去并保存。

### 提示「API Key 无效或已过期」

密钥被禁用、过期，或后台改了分组。请联系管理员换一把新的，再按上面的步骤重新粘贴。

### 提示额度不足或生成失败

额度由后台的子密钥控制。请联系管理员确认这把 Key 的剩余次数与可用模型。

### 模型列表里没有想要的模型

可选模型随应用版本内置，未在列表中的模型请联系管理员确认是否已开放。
