# 问题排查

遇到问题不要慌，本文介绍如何排查和解决常见问题。

## 常见问题

### AI 生成功能不可用

**症状**：点击发送后没有反应，或提示错误

**排查步骤**：

1. **检查网络连接**
   - 确保网络正常
   - 尝试刷新页面

2. **检查 API 配置**
   - 点击工具栏的企业微信图标，打开「配置 API Key」弹窗
   - 确认已粘贴管理员发放的 API Key；提示「无效或已过期」时找管理员换一把新的

3. **检查 API 额度**
   - 登录 API 服务商后台查看余额

4. **查看任务失败原因**
   - 在任务队列里点开失败的任务，看提示信息

### 页面加载缓慢或空白

**症状**：页面长时间白屏或加载很慢

**解决方法**：

1. **清除浏览器缓存**
   - 在浏览器设置里清除本站的缓存数据
   - 刷新页面

2. **硬刷新**
   - Windows: `Ctrl + Shift + R`
   - Mac: `Cmd + Shift + R`

3. **检查浏览器兼容性**
   - 推荐使用 Chrome、Edge、Safari 最新版
   - 不建议使用 IE 浏览器

### 素材库图片不显示

**症状**：素材库中的图片显示为空白或加载失败

**解决方法**：

1. **检查存储空间**
   - 浏览器本地存储可能已满
   - 删除不需要的素材释放空间

2. **刷新页面重新缓存**
   - 刷新后素材会重新读取本地缓存
   - 仍不显示时，删除该素材后重新上传

### 数据丢失

**症状**：项目或素材突然消失

**可能原因**：

1. **浏览器数据被清除**
   - 检查是否使用了"清理工具"
   - 检查浏览器隐私设置

2. **使用了无痕/隐私模式**
   - 无痕模式关闭后数据会丢失
   - 请使用正常模式

**预防措施**：

- 定期使用 **备份恢复** 功能导出数据
- 重要项目及时导出为 PNG 或 JSON 文件

### 视频生成一直等待

**症状**：视频任务长时间显示"处理中"

**说明**：

视频生成需要较长时间（1-5 分钟甚至更长），这是正常的。

**如果超过 10 分钟**：

1. 在任务队列中查看任务状态
2. 如果显示失败，点击 **重试**
3. 反复失败时，点开任务查看提示信息，并把提示截图发给管理员

### 快捷键不生效

**可能原因**：

1. **焦点在输入框中**
   - 点击画布空白区域，确保焦点在画布上

2. **与浏览器快捷键冲突**
   - 某些快捷键可能被浏览器占用
   - 尝试使用工具栏按钮代替

3. **输入法干扰**
   - 切换到英文输入法
   - 关闭输入法后重试

## 获取技术支持

如果以上方法无法解决问题：

### 1. 收集信息

- 截图问题界面
- 记录操作步骤
- 出现报错弹窗时，点 **导出错误日志** 保存日志文件

### 2. 联系方式

- **联系管理员**: 微信扫码，或点工具栏的企业微信图标
